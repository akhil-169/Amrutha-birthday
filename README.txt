# Birthday Envelope Website 💌

A soft-pink birthday wish page with an animated envelope, sliding letter, hearts and confetti.

## Run it
1. Extract the ZIP.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html to open it in your browser.

## Personalize it
Edit recipientName and senderName in script.js. The birthday wishes are in index.html inside the letter-body section.

## Publish it
Upload the website files to a static hosting service such as Netlify Drop or GitHub Pages to get a public link.
